## 얼굴을 빼는 것이 첫 번째 작업이다

줌/밋 녹화본은 **왼쪽 화면공유 + 오른쪽 참가자 웹캠 타일** 레이아웃이다.
공개 영상에 커뮤니티 멤버 얼굴이 나가면 안 된다.

0819 의 네 녹화본은 전부 타일이 `x ≥ 960` 에 몰려 있어 `crop=960:540:0:80` 로
잘라냈다. **다른 녹화본은 레이아웃이 다를 수 있으니 값을 그대로 믿지 말고
프레임을 떠서 확인한다.**

```bash
# 후보 시점의 프레임을 떠서 크롭 경계를 눈으로 잡는다
ffmpeg -v error -ss 1500 -i "<녹화본>" -frames:v 1 /tmp/probe.png
# 정한 크롭으로 전 녹화본을 한 장씩 다시 떠서 얼굴이 사라졌는지 확인
```

크롭이 b-roll 품질도 올린다 — 화면공유가 프레임을 꽉 채우게 되니까.
단 참가자 타일 제거가 조작 메뉴·탭·터미널을 자르는 근거는 아니다. 배치를 바꾸면
적용 전/후 합성 프레임으로 확인하고 필요한 화면 정보를 보존한다.

## 무음은 구조로 보장한다

볼륨 0 이 아니라 **오디오 스트림 자체를 만들지 않는다.**

1. 추출할 때 `-an`
2. 컴포지션에서 이 클립들에 `<audio>` 를 달지 않음 (`muted` 속성만으로 끝내지 말 것)
3. 합성에서 `-map 1:a` 로 head 만 가져옴
4. 스테이징 스크립트가 마지막에 `ffprobe` 로 오디오 스트림 부재를 확인

검증은 **b-roll 유무 두 컷의 디코딩 오디오 해시 비교**가 결정적이다.

```bash
for f in output.mp4 output-broll.mp4; do
  printf "%-20s " "$f"
  ffmpeg -v error -i "$f" -vn -f s16le -ar 48000 -ac 2 - 2>/dev/null | shasum -a 256 | cut -c1-32
done
# 같으면 b-roll 이 오디오에 기여한 게 0
```

## 해상도

풀프레임으로 쓸 클립은 **1920×1080 으로 굽는다.**

```bash
-vf "crop=960:540:0:80,scale=1920:1080:flags=lanczos,fps=30" \
-g 30 -keyint_min 30    # HyperFrames 가 프레임마다 seek 한다. sparse GOP 이면 프리즈
```

크롭 결과가 960×540 인데 그대로 두면 브라우저가 2배 bilinear 업스케일을 해서
화면 속 글자가 뭉갠다. 정보량은 어차피 같지만 lanczos 로 한 번 구워 넣는 쪽이 낫다.

## 배치

`storyboard.json` 의 카드에 붙인다.

```json
{ "media": { "mode": "panel", "kind": "video",
             "src": "media/meetup.mp4", "full": [8.0, 5.0] } }
{ "media": { "mode": "mosaic",
             "srcs": ["media/a.jpg", "media/b.jpg", ...] } }
```

| mode | 자리 | 쓰임 |
| --- | --- | --- |
| `panel` | `980,196` 844×475 | 단일 클립/이미지 |
| `mosaic` | `980,274` 3×2 그리드 | 썸네일 여러 장 |

`full: [오프셋, 지속]` — 카드 시작 기준. 3~5초가 적당하고, 짧은 카드(<8초)는
2.5초쯤. 전환은 패널을 transform 으로 키운다:

```js
tl.to(M, { scaleX: 2.27488, scaleY: 2.27368, x: -442, y: 106.5,
           borderRadius: 0, borderWidth: 0, duration: 0.6, ease: 'power2.inOut' }, t0);
```

844×475 가 (980,196) 에 있고 캔버스가 같은 16:9 이므로 정확히 덮인다. 두 축 배율이
0.05% 다르니 **`scale` 하나로 쓰지 말 것** — 한쪽에 머리카락 굵기 틈이 남는다.

전환 중에는 `.root` 를 페이드아웃한다. 안 그러면 커지는 패널이 헤드라인 위를
쓸고 지나가서 컷이 아니라 가림으로 읽힌다.

## 고르는 기준

- **카드가 하는 말을 실제로 뒷받침하는 화면만.** "3기 세무사님" 카드에는 아무것도
  얹지 않았다 — 어느 프로젝트가 그분 것인지 모르는데 아무 썸네일이나 얹으면
  영상이 거짓말을 한다.
- **대비를 보고 고른다.** 쇼케이스 썸네일 절반이 흰 대시보드라 그대로 6장을 깔면
  모자이크가 흰 덩어리가 된다. 어두운 것과 섞는다.
- 6분에 7군데, 그중 풀프레임 21초 정도가 과하지 않았다.
