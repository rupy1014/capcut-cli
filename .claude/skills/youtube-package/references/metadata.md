# 제목 · 설명 · 태그

출처: `~/sideProjects/youtube/.claude/agents/seo-optimizer.md` + 같은 저장소 `CLAUDE.md`
의 Writing rule. 값은 그대로 가져왔다.

## 제목

- **70자 이내**
- **숫자 / 변화 / 결과물을 포함한다.** 이게 필수 조건이다
- 추상적이지 않게 — 주제가 바로 보이게
- 호기심 유발 + 구체적 약속. 단 겁주기로 만들지 않는다

```
✕  ai 공부, 이렇게 하면 됩니다              추상적
✕  ai 공부법 모르면 손해입니다              겁주기
✕  비개발자 130명, 프로젝트 100개 — 초보자를 위한 ai 공부법 4가지
                                          숫자를 앞에 밀어넣어 한 문장으로 안 읽힌다
○  AI 완전 초보자를 위한 정석 공부법 4가지
```

**숫자를 앞세워 제목을 채우지 마라.** 규칙은 "숫자를 포함한다" 이지 "숫자로
시작한다" 가 아니다. 제목은 먼저 **한 문장으로 읽혀야** 하고, 숫자는 그 문장을
구체화하는 자리에 하나만 붙인다. 근거가 되는 다른 숫자들은 썸네일 서브와
설명이 받는다.

프레임을 만드는 단어는 **영상 안에 있는 말**에서 고른다. 위 예의 `정석` 은
화자가 실제로 한 말("'수학의 정석'처럼 삼아서")이다. 밖에서 가져온 수식어는
제목이 약속한 것을 본문이 못 지키게 만든다.

숫자는 **최종 영상에서 실제로 남은 발화**여야 한다. 퇴고된 자막과 최종 영상으로 확인한다.
대본은 즉흥 강의의 구조·내용 근거가 아니다. 용어·표기는 화면녹화 프레임과 대조하고
뜻을 바꾸는 교정은 하지 않는다. 확신 없으면 원문 유지 + 사용자 확인 목록으로 남긴다.

## 설명

총 300~500자.

```
1줄        호기심 유발 질문
2~3줄      핵심 내용 요약 (사례·근거 포함)
(빈 줄)
챕터        00:00 형식, 최종 영상의 내용 전환에서 뽑는다
(빈 줄)
링크        고정 댓글로 뺄 것 / 여기 둘 것 구분
(빈 줄)
해시태그    5~8개
```

카드형은 **최종 컷·배속을 반영한** storyboard 섹션을 후보로 쓰고 MP4의 시작 장면과
대조한다. 카드 없는 즉흥 강의는 최종 영상 기준이며 대본 순서를 강제하지 않는다.

주장만 적지 말고 사례를 같이 적는다. "다양한 분들이 참여했다" 보다
"떡집 사장님, 도어락 기사, 변리사, 세무사, 교수님" 이 강하다.

## 태그

20~30개, **합계 500자 이내.** 네 그룹으로 구성한다.

| 그룹 | 개수 | 역할 |
| --- | --- | --- |
| 채널 고정 | 5~6 | 매 편 동일. 채널 인지도 축적 |
| 주제 | 3~5 | 이 영상의 핵심 키워드 |
| 현실 연결 | 3~5 | 비대상 유입용. 비개발자도 검색할 말 |
| 롱테일 | 3~5 | 2~3단어 복합 검색어. 경쟁 낮고 전환 높음 |

채널 고정 태그는 한 번 정하면 바꾸지 않는다. 정해진 게 없으면 사용자에게 묻는다.

```python
tags = [...]
assert 20 <= len(tags) <= 30, len(tags)
assert sum(len(t) for t in tags) + len(tags) - 1 <= 500   # 콤마 포함
```

## 썸네일 문구

- 한 줄 **8자 이내**(공백 포함), 2줄
- 마지막 줄에 핵심어를 실어 accent 색으로
- 6자까지가 가장 크게 렌더된다 (132px). 7자·8자는 120·108px 로 자동 축소
- 9자를 넘기면 박스를 벗어난다

제목과 같은 말을 반복하지 않는다. 제목이 설명하면 썸네일은 **찌른다.**
